# موبیکس — نسخه اندروید

این نسخه برای مدیریت تعمیرات موبایل ساخته شده و پیامک را از خود سیم‌کارت گوشی ارسال می‌کند؛ شماره مجازی یا پنل پیامکی ندارد.

قابلیت‌ها:
- ثبت مشتری، شماره، مدل، IMEI، مشکل، قطعات و هزینه
- کد پذیرش ۶ رقمی
- تغییر وضعیت: در انتظار بررسی / در حال تعمیر / آماده تحویل / تحویل شد
- ارسال پیامک دستی
- ارسال خودکار پیامک هنگام تغییر وضعیت (قابل فعال/غیرفعال کردن)
- ذخیره اطلاعات داخل خود گوشی
- پیامک فارسی به صورت چندبخشی برای متن‌های طولانی

ساخت:
1. پوشه را در Android Studio باز کن.
2. Gradle Sync را اجرا کن.
3. گوشی اندرویدی را با USB debugging وصل کن یا از APK debug استفاده کن.
4. هنگام اولین ارسال، مجوز SMS را تأیید کن.

نکته: برای ارسال مستقیم از سیم‌کارت، برنامه به SEND_SMS نیاز دارد و اندروید این مجوز را به صورت runtime کنترل می‌کند.

نام فروشگاه در برنامه: موبیکس (Mobix)
